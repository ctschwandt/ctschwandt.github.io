## Overview

A JavaFX Othello implementation with configurable boards, full game rules, and persistent game state.

## Implementation

- Built a JavaFX implementation of Othello with configurable board sizes, a setup mode for custom starting positions, and a responsive resizable UI.
- Implemented fully enforced game rules including legal move detection, piece flipping, turn progression, and end-game scoring.
- Added save/load support by serializing game state (board, turn, and settings) into a persistent text format.
