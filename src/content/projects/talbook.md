## Overview

A collaborative music-gear marketplace with listings, user feeds, messaging, and relational data.

## Implementation

- Co-developed a marketplace-style web application for music gear, implementing core features including listings, user feeds, and direct messaging.
- Designed and integrated a relational MySQL schema supporting users, items, posts, messaging, and search functionality.
